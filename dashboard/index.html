HBase Row Key Anatomy

customer_id # transaction_date # transaction_id

Example: CUST1001#2025-01-10#TXN10005782

  • Clustering: Clustered on disk by customer ID for high cache locality.
  • Time Ordering: Lexicographical sorting provides chronological order.
  • Range Scans: Enables fast historical range queries (e.g. all transactions of March 2025).
  • Hotspot Prevention: Distributes writes across RegionServers instead of single-timestamp contention.
